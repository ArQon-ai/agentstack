# Agent Economics: Unit Economics for AI Agent Businesses

*Understanding the economics of agent-powered products.*

---

## The Unit Economics Framework

For any agent product, you need to understand:

```
Unit Economics = Revenue per Task - Cost per Task
```

If this is positive at scale, you have a business.

---

## Revenue Models

### 1. Per-Task Pricing

**Best for:** Variable usage, clear value per task

```
$0.50 per task completed
Customer does 100 tasks/month = $50/month
```

**Pros:**
- Aligns with value
- Scales with usage
- Easy to understand

**Cons:**
- Unpredictable costs for customers
- Hard to budget
- Usage anxiety

---

### 2. Subscription (Tiered)

**Best for:** Regular usage, predictable value

```
Starter: $49/month (100 tasks)
Pro: $149/month (500 tasks)
Enterprise: $499/month (unlimited)
```

**Pros:**
- Predictable revenue
- Easy to budget
- Encourages usage

**Cons:**
- Overages cause friction
- Hard to set limits
- Usage anxiety at tier edges

---

### 3. Outcome-Based

**Best for:** High-value, measurable outcomes

```
$5 per successful lead generated
$50 per support ticket resolved
$100 per document processed
```

**Pros:**
- Perfectly aligned incentives
- Customer pays for results
- Easy to justify

**Cons:**
- Hard to define "success"
- Dispute risk
- Cash flow uncertainty

## Cost Structure

### Variable Costs (per task)

| Cost | Typical Range |
|------|--------------|
| LLM API | $0.01 - $0.50 |
| Tool/API calls | $0.00 - $0.10 |
| Infrastructure | $0.001 - $0.01 |
| Monitoring | $0.001 - $0.005 |
| **Total Variable** | **$0.02 - $0.62** |

### Fixed Costs (per month)

| Cost | Typical Range |
|------|--------------|
| Development | $5,000 - $50,000 |
| Infrastructure | $100 - $2,000 |
| Support | $1,000 - $10,000 |
| Marketing | $500 - $10,000 |
| **Total Fixed** | **$6,600 - $72,000** |

## Break-Even Analysis

### Scenario: Support Agent Product

**Pricing:** $149/month per seat
**Variable cost:** $0.15 per task
**Tasks per seat:** 200/month

```
Revenue per seat: $149
Variable cost: $0.15 × 200 = $30
Contribution margin: $149 - $30 = $119

Fixed costs: $20,000/month
Break-even: $20,000 / $119 = 168 seats
```

At 500 seats:
```
Revenue: $74,500
Variable costs: $15,000
Contribution: $59,500
Fixed costs: $20,000
Profit: $39,500 (53% margin)
```

## Optimizing Unit Economics

### Reduce Variable Costs

1. **Model Routing**
   ```
   Before: All tasks use GPT-4 ($0.03/1K tokens)
   After: 70% use GPT-3.5 ($0.0015/1K), 30% use GPT-4
   Savings: 60%
   ```

2. **Caching**
   ```
   Cache hit rate: 30%
   Savings: 30% of API costs
   ```

3. **Context Optimization**
   ```
   Reduce tokens by 50%
   Savings: 50% of API costs
   ```

### Increase Revenue per Task

1. **Upsells**
   - Premium features
   - Priority processing
   - Advanced analytics

2. **Usage Expansion**
   - More tasks per user
   - More users per account
   - More use cases

3. **Value Demonstration**
   - ROI calculators
   - Case studies
   - Usage reports
