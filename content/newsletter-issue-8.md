# Hiring Your First Employee: When and How for Agent Businesses

*The transition from solo to team.*

---

## When to Hire

### The Triggers

**Hire when:**
- Revenue is consistent ($15K+/month)
- You're working 60+ hours/week
- You're turning down work
- Quality is slipping
- You need skills you don't have

**Don't hire when:**
- Revenue is volatile
- You're under $10K/month
- You haven't productized
- You enjoy the solo work
- You can automate instead

---

## Who to Hire First

### Option 1: Junior Developer

**Best for:** Technical founders who need execution help

**Pros:**
- Affordable ($3-5K/month)
- Moldable
- Handles implementation

**Cons:**
- Needs training
- Can't work independently
- Quality control needed

**When:** You have more work than time, but clear specs

---

### Option 2: Virtual Assistant

**Best for:** Business-focused founders

**Pros:**
- Very affordable ($500-1K/month)
- Handles admin
- Frees up your time

**Cons:**
- Limited technical skills
- Needs clear processes
- Not scalable

**When:** You're spending 10+ hours/week on admin

---

### Option 3: Technical Content Writer

**Best for:** Content-heavy businesses

**Pros:**
- Medium cost ($2-3K/month)
- Maintains content velocity
- Industry knowledge

**Cons:**
- Needs guidance
- Voice consistency
- Review required

**When:** Content is 50%+ of your strategy

---

## The Hiring Process

### Step 1: Define the Role

```
Title: Junior Agent Engineer

Responsibilities:
- Implement agent features
- Write tests
- Fix bugs
- Document code

Requirements:
- Python proficiency
- Basic LLM knowledge
- Git experience
- Self-starter

Nice to have:
- FastAPI experience
- OpenAI API experience
- Open source contributions
```

### Step 2: Find Candidates

**Sources:**
- Twitter (your audience)
- GitHub (contributors)
- Newsletter subscribers
- Referrals
- Upwork (for VAs)

**Best source:** Your community.
They already know your work.

### Step 3: The Test Project

**Don't:**
- Rely on resumes
- Trust interviews alone
- Hire based on enthusiasm

**Do:**
- Paid test project ($200-500)
- Real work, not toy problems
- 1-week timeline
- Clear evaluation criteria

**Example test:**
"Build a simple agent that summarizes articles from a URL.

Requirements:
- FastAPI endpoint
- Error handling
- Tests
- Documentation

Budget: 10 hours @ $50/hr = $500"

### Step 4: The Offer

**Structure:**
- Base: $X/month
- Hours: 20-40/week
- Remote: Yes
- Trial: 1 month
- Equity: Optional (0.5-2%)

**Benefits:**
- Flexible hours
- Learning opportunities
- Open source work
- Career growth

## Management

### The 1-on-1

**Weekly, 30 minutes:**
- What went well?
- What's blocked?
- What do you need?
- What's next?

### Documentation

**Create:**
- Role responsibilities
- Decision-making framework
- Communication norms
- Code review process
- Escalation path

### Autonomy

**Give:**
- Clear outcomes
- Not instructions
- Trust to execute
- Support when needed

## Common Mistakes

### 1. Hiring Too Early
**Fix:** Wait for $15K/month consistent revenue.

### 2. Hiring the Wrong Role
**Fix:** Track your time. Hire for your biggest time sink.

### 3. Not Documenting
**Fix:** Document before hiring. Not after.

### 4. Micromanaging
**Fix:** Hire for outcomes. Let them figure out how.

### 5. No Trial Period
**Fix:** Always do 1-month trial. Both sides evaluate.
