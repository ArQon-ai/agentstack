# AI Agent UX: Designing Conversational Interfaces

*Design agents users love.*

---

## UX Principles

### 1. Clear Capabilities

```markdown
✅ Good:
"I can help you with:
→ Answering questions
→ Writing code
→ Analyzing data
→ Creating content"

❌ Bad:
"I'm an AI assistant."
```

### 2. Set Expectations

```markdown
✅ Good:
"This will take 30 seconds to generate."

❌ Bad:
[Loading spinner with no text]
```

### 3. Handle Errors Gracefully

```markdown
✅ Good:
"I couldn't find that information. Try rephrasing or asking about something else."

❌ Bad:
"Error 404"
```

---

## Design Patterns

### Progressive Disclosure

```
User: "Help me write code"

Agent: "What language?"
[Show: Python, JavaScript, Rust]

User: "Python"

Agent: "What type of script?"
[Show: Web, Data, Automation]
```

### Confirmation

```
Agent: "I'll delete all files. Confirm?"
[Yes] [No]
```

---

## The UX Checklist

- [ ] Clear capabilities
- [ ] Set expectations
- [ ] Show progress
- [ ] Handle errors
- [ ] Allow undo
- [ ] Offer suggestions
- [ ] Learn preferences
- [ ] Respect time
- [ ] Be predictable
- [ ] Test with users

Agent UX:
