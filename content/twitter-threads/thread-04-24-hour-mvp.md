# Twitter Thread #4: We Built an MVP in 24 Hours Using Vibe Coding

Last week, we built a fully functional customer support dashboard.

24 hours. From idea to deployed.

Here's exactly how we did it (and what we used): 👇

Hour 0-4: The Vibe

• Claude 3.5 Sonnet for logic

• Supabase for database (instant setup)

Result: Working prototype with auth, dashboard, and ticket management.

Hour 4-8: The Hardening

• Added rate limiting
• Removed hardcoded secrets

The AI wrote the code. We reviewed and secured it.

Hour 8-12: The Polish

• Loading states

• Empty states

The details that separate prototypes from products.
