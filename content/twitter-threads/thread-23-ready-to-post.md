"Did the agent accomplish what the user wanted?"

"How much did we spend to get a good outcome?"

Includes:
→ Model costs
→ Retry costs
→ Tool costs
→ Human review costs

**Tweet 5/8:**
```
Metric 3: User Satisfaction

"Did the user feel helped?"

Measure via:
→ Explicit feedback (thumbs up/down)
→ Implicit signals (time to next query, re-asks)
→ Session length (too short = didn't help, too long = confused)

Users are the ultimate judges.
```

**Tweet 6/8:**

Metric 4: Escalation Rate

"How often does the agent give up?"

High escalation:
→ Agent isn't capable enough
→ Users are frustrated
→ Humans are overloaded

Low escalation:
→ Agent handles most cases
→ But might be overconfident
→ Missing edge cases

Sweet spot: 5-15% escalation
```

**Tweet 7/8:**
```
Metric 5: Confidence Calibration

"When the agent is confident, is it right?"

Well-calibrated:
→ 90% confidence = 90% accuracy
→ 70% confidence = 70% accuracy

Poorly calibrated:
→ 90% confidence = 60% accuracy (overconfident)
→ 50% confidence = 80% accuracy (underconfident)

Track the correlation.
Adjust thresholds.
